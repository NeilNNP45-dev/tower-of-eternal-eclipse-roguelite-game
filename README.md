# 🌑 Tower of Eternal Eclipse

A strategic, turn-based roguelite dungeon crawler built entirely in Python from scratch.

*Climb the mysterious Tower of Eternal Eclipse, battle dangerous enemies, defeat powerful bosses, and optimize your build to survive. Every run is a test of strategy, resource management, and tactical decision-making.*

---

## 🎮 Key Features

### ⚔️ Class-Based Gameplay

Choose from distinct character classes, each featuring unique attribute scaling, custom baseline stats, and specialized abilities.

### 👹 Boss Encounters

Battle powerful bosses throughout your climb, each requiring different strategies and resource management to defeat.

### ⚡ Tactical Turn-Based Combat

A calculated combat system where managing abilities, cooldowns, and health is the difference between victory and defeat.

### 📈 Character Progression

Grow stronger as you ascend deeper into the tower by improving your character's stats and mastering your chosen class.

### 🎲 Roguelite-Inspired Design

Scaling difficulty and strategic decision-making encourage players to adapt and improve with every run.

### 🧪 Automated Testing & Balancing

To help balance the game without having to manually play through it thousands of times, I built a separate tool called "TestingAutoBot.py".

This script runs automated battle simulations, allowing me to quickly test gameplay changes and gather data on:

- Class Balance – Checking whether a class is significantly stronger or weaker than intended.
- Boss Difficulty – Ensuring bosses scale appropriately and provide a meaningful challenge.

By combining these automated simulations with manual playtesting, I can fine-tune combat balance while preserving each class's unique strengths, weaknesses, and playstyle.

## 🚀 Getting Started

### Prerequisites

* Python 3.8 or higher

### Installation

Clone the repository:

```bash
git clone https://github.com/NeilNNP45-dev/tower-of-eternal-eclipse-roguelite-game.git
```

Navigate into the project directory:

```bash
cd tower-of-eternal-eclipse-roguelite-game
```

Launch the game:

```bash
python main.py
```
